# Security Policy

## Supported Versions

Security fixes are applied to the current `main` branch and the latest published release. Historical tags are not maintained as separate supported versions.

## Reporting a Vulnerability

Please report suspected vulnerabilities through [GitHub Private Vulnerability Reporting](https://github.com/Dennylunch/TrainForge/security/advisories/new).

Do not open a public issue for a vulnerability and do not include credentials, API keys, personal data, or working exploits in public discussions.

Include the following when possible:

- The affected route, component, or configuration.
- Reproduction steps and the expected security boundary.
- Potential impact and any known mitigations.
- Whether the issue has been disclosed elsewhere.

Reports should receive an initial acknowledgement within seven days. Confirmed issues will be assessed, fixed, and disclosed in a coordinated manner appropriate to their severity.

## Scope Notes

The public demo is an evaluation environment with disposable SQLite data. Do not enter real client, health, or credential data. AI-assisted content must be reviewed by a qualified person and should not be treated as medical advice.
